01 · Problem

숫자는 정확해도 해석은 틀릴 수 있습니다.

환경영향 평가계수는 서로 다른 기준 단위와 결측값을 포함합니다. 계수만 비교해 제품 전체의 친환경성을 판단하면 오해가 생깁니다. Looply는 데이터의 범위와 한계를 함께 보여주는 분석 경험을 목표로 만들었습니다.

02 · Solution

네 가지 분석 경험

01. 분석 리포트

데이터 구성, 분포, 영향범주 간 관계와 군집 패턴을 시각적으로 탐색합니다.

02. 환경영향 계산

항목과 사용량을 선택해 개별 평가계수 기반의 부분 환경영향을 계산합니다.

03. 데이터 인사이트

로그 분포, 박스플롯, 산점도, Spearman 순위상관을 살펴봅니다.

04. 군집 분석

KMeans와 실루엣 기반 탐색으로 유사한 수치 패턴을 찾습니다.

03 · Engineering

검증된 계산과 생성형 설명을 분리했습니다.

데이터 준비
Python/Pandas 정제 → 398개 항목 → 웹 시각화 데이터

분석과 시각화
JavaScript·Plotly 기반 탐색, 부분 계산, 군집 분석

AI 해설
FastAPI에서 근거 기반 핵심 사실을 고정하고 AI가 쉬운 한국어 설명을 생성

오류 방어
수치 환각 및 알려진 과도한 해석 차단, 안전한 기본 해설로 대체, 회귀 테스트

04 · Verification

실제 오류를 테스트로 남겼습니다.

초기 AI는 시멘트의 탄소발자국 계수 차이를 전체 환경영향 차이로 일반화했습니다. 데이터 수가 적다는 이유로 자료가 부족하다고 단정하기도 했습니다. 이를 발견한 뒤 사실 생성과 설명 생성을 분리하고, 두 오류를 자동 테스트에 추가했습니다.

2026-10-16 제공된 GitHub Actions 로그 기준 Python 테스트 12개 통과. 개발 미리보기에서 AI 해설과 기존 차트 동작을 수동 확인했습니다.
05 · Scope

프로젝트의 한계도 명확히 설명합니다.

이 프로젝트는 공개 평가계수의 탐색과 부분 계산을 위한 학습·취업 포트폴리오입니다. 완전한 제품 LCA, PCF 산정 또는 EPD 인증 결과가 아닙니다. AI 해설도 전문 검증을 대체하지 않습니다.
