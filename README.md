# Beyond Carbon: 탄소발자국만 보면 놓치는 것들

> 환경성적표지(EPD) 평가계수 398건으로, **탄소발자국이 다른 환경영향을 얼마나 대신 보여 줄 수 있는지** 검증한 데이터 분석

**[분석 리포트 열기](https://goalbangg-prog.github.io/Looply-mini-LCA/)** · [분석 코드](analysis/reanalysis.py) · [정제 노트북](notebooks/data_preprocessing.ipynb) · [정제 데이터](data/lca_factors_clean.csv)

## 질문

제품의 환경성을 탄소발자국 하나로 이야기하는 경우가 많습니다. 탄소발자국이 낮은 원료는 다른 환경영향도 낮을까요? 탄소발자국으로 영향이 큰 원료를 골라 관리하면, 물 사용이나 부영양화가 큰 원료도 함께 잡힐까요?

## 핵심 결과

| 결과 | 숫자 |
|---|---|
| 탄소발자국과 물소모는 순위가 거의 따로 움직인다 | ρ 0.32 (95% 구간 0.15~0.49, 원료 163종) |
| 탄소 상위 20%로 걸러내면 부영양화·물소모 상위 원료의 절반 이상을 놓친다 | 포착률 41%, 42% (무작위 기준 20%) |
| 탄소 순위보다 다른 영향 순위가 40%p 이상 높은 원료 | 187종 중 25종 (기준 30%p면 37종, 50%p면 16종) |
| 소재군을 나눠 봐도 결론은 같다 | 6개 소재군 모두 탄소–물소모 < 탄소–자원 |

산성화(ρ 0.81)와 자원발자국(0.74)은 탄소발자국과 함께 움직였습니다. 탄소발자국은 연소 관련 영향은 잘 대신하지만, 물과 영양물질 부담은 따로 확인해야 합니다.

## 분석 방법

1. **빈 값 확인:** “해당없음”을 0으로 채우지 않고 빈 값으로 두었습니다. 연료 사용·화학반응 단계는 탄소발자국만 있고, 오존층영향은 원료 단계의 93%가 비어 있어 뺐습니다.
2. **비교 범위:** 단위가 다른 항목은 섞지 않았습니다. 원료 및 에너지 생산 단계, 단위 kg, 수자원 제외 187종을 원료 풀로 삼았습니다.
3. **관계:** 값이 수십만 배까지 차이 나서 Spearman 순위상관을 쓰고, 부트스트랩(2,000회)으로 95% 구간을 구했습니다.
4. **실무 질문으로 바꾸기:** 탄소 상위 20%로 걸렀을 때 다른 영향 상위 20%를 얼마나 함께 잡는지(선별 포착률) 계산했습니다.
5. **기준 민감도:** ‘놓치는 원료’ 기준을 20~70%p로 바꿔도 물소모가 가장 많이 놓치는 영향이라는 결과가 유지되는지 확인했습니다.
6. **수송·폐기:** 단계 안에서만 비교했습니다. 재활용 계수 9건이 모두 양수라 회피 부하가 빠졌을 가능성이 있고, 원자료로 확인할 수 없어 소각과의 비교 해석을 보류했습니다.
7. **군집(부록):** K-means로 묶어 봤지만 실루엣 0.33, 기준에 따른 일치도 0.55~0.69로 경계가 흐려 결론에 쓰지 않았습니다.

분석 중 내린 판단 11가지와 그 이유, 다르게 했을 때의 결과는 리포트 7장에 정리했습니다.
