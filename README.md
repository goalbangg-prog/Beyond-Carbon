# LCA mini 계산기 🌱

한국환경산업기술원 환경성적표지 평가계수(2021-08-02 파일)를 활용한 **환경영향계수 계산·데이터 탐색·군집화 학습용 웹앱**입니다.

> **중요:** 이 앱은 공개 평가계수 기반의 부분 계산 및 탐색 도구입니다. ISO 14040/14044를 충족하는 완전한 전과정평가(LCA), 제품탄소발자국(PCF) 또는 환경성적표지(EPD) 인증 결과가 아닙니다.

## 주요 기능

| 화면 | 기능 | 시각화 |
|---|---|---|
| 환경영향 계산 | 사용량 × 단위당 평가계수, 여러 항목 합산, 단위 변환, CSV 저장 | 항목별 막대그래프, 영향범주별 기여율 히트맵, 대분류별 도넛그래프 |
| 데이터 탐색 | 동일 기준 단위 내 계수 순위·분포·관계 분석 | 가로 막대, log10 히스토그램, 구분별 박스플롯(로그 축), 산점도(로그 축), Spearman 상관계수 히트맵 |
| 유사 원료 묶기 | 양수 계수 log10 변환 → 표준화 → KMeans | 군집별 중심값 히트맵, 군집 산점도, 군집별 항목표 |
| 이용 안내 | 방법론적 범위·결측값 주의·단위 변환기 | — |

그래프는 **Plotly.js**로 구현되어 확대·축소, 마우스 오버, PNG 내보내기를 지원합니다. Plotly 라이브러리는 저장소의 `plotly.min.js`를 사용하므로 외부 CDN에 의존하지 않습니다.

## 데이터 처리 및 계산

- 원본 데이터: 한국환경산업기술원 환경성적표지 평가계수(2021-08-02 제공 파일)
- 정제 데이터: **398행**, 탄소·자원·산성비·부영양화·물소모의 5개 영향 범주
- Pandas로 인코딩, 숫자형 변환, `해당없음` 결측 처리, 중복·단위·결측률을 점검했습니다.
- 계산식: **환경영향량 = 기준 단위로 환산한 사용량 × 평가계수**
- 결측 계수는 0으로 대체하지 않으며, 합계가 불완전할 수 있음을 표시합니다.
- 서로 다른 환경영향 범주 간 절댓값을 직접 비교하거나 합산하지 않습니다.
- 구분별 계수 비교는 **동일 기준 단위** 내에서만 수행합니다.

## 실행 방법

**GitHub Pages:** 저장소 루트의 `index.html`, `lca_data.js`, `plotly.min.js`가 모두 필요합니다. 저장소의 **Settings → Pages → Deploy from a branch → main / (root)**에서 배포합니다.

**Streamlit 원본:** `python/app.py`가 정제 CSV를 찾을 수 있도록 경로를 확인하고 다음 명령을 실행합니다.

```bash
pip install -r python/requirements.txt
streamlit run python/app.py
```

## Python과 웹 버전의 차이

- Python 원본은 Altair 차트와 scikit-learn KMeans를 사용합니다.
- 웹 버전은 Plotly.js로 주요 차트를 복원했으며, 군집 분석에는 브라우저용 자체 KMeans 구현을 사용합니다.
- **군집 초기화가 다르므로 Python과 웹의 군집 결과는 동일하다고 보장할 수 없습니다.** 웹의 군집 수·해석은 탐색용입니다.
- 군집 프로필 히트맵의 값은 **log10 변환 후 표준화한 군집 중심값**이며 원래 환경영향계수가 아닙니다.
- 산점도 및 박스플롯의 로그 축은 **양수 값**에만 적용합니다.
