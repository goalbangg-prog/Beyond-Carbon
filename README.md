## 2. 네 가지 핵심 기능

### ① 분석 리포트
스크롤 기반 서사형 데이터 분석 리포트입니다. 데이터 범위 → 평가계수 분포 → 영향범주 간 관계 → 군집 특징 → 방법론 및 한계 순으로 분석 흐름을 설명합니다. 차트 옆에 데이터 기반 해설과 용어 설명을 배치했습니다.

### ② 환경영향 계산
활동자료 사용량을 해당 계수의 기준 단위로 변환한 뒤 영향범주별 부분 결과를 계산합니다.

```text
부분 환경영향량 = (계수 기준 단위로 환산한 사용량) × (단위당 평가계수)
```

여러 항목을 선택해 결과를 살펴보고, 기여도를 차트로 비교하고 CSV로 내보낼 수 있습니다. **영향범주가 서로 다르면 단위를 무시한 채 합산하지 않으며**, 결측값을 임의로 0으로 대체하지 않습니다.

### ③ 데이터 인사이트
동일 단계·기준 단위의 데이터를 대상으로 분석합니다.

- 계수 순위: 평가계수가 큰 항목 비교
- 로그 분포: log₁₀ 변환 히스토그램
- 구분별 분포: 박스플롯
- 두 영향 항목 비교: 산점도, 양수값의 로그축
- Spearman 순위상관: 영향범주 간 단조 관계를 탐색하는 히트맵

표시 명칭은 **탄소발자국·자원발자국·산성화·부영양화·물발자국**으로 통일했습니다. 보조 영향 항목은 산점도에서 사용합니다.

### ④ 군집 분석
양수·유효 평가계수를 로그 변환 및 표준화한 뒤 유사한 환경영향 특징을 묶어 탐색합니다. 군집 수(k)에 대한 실루엣 기반 추천, 군집별 특성, 대표 항목을 확인할 수 있도록 확장했습니다. **웹의 JavaScript KMeans 구현과 Python의 scikit-learn 구현은 초기화·동작이 달라 결과가 완전히 같다고 보장하지 않습니다.**

## 3. 데이터와 해석 기준

**원자료 계보:** 한국환경산업기술원 환경성적표지 평가계수(2021-08-02 제공 자료) → Python/Pandas 정제 → `data/lca_factors_clean.csv` → `lca_data.js` → 브라우저 시각화.

- 평가계수 398개 항목을 사용합니다. 데이터 항목 수가 실제 제품 398개의 LCA 결과를 뜻하지는 않습니다.
- 환경영향범주는 탄소발자국, 자원발자국, 산성화, 부영양화, 물발자국입니다.
- 평가계수의 기준 단위가 다르면 직접 크기를 비교하지 않습니다. 단위 변환은 물리적으로 호환되는 범위에서만 가능합니다.
- 로그축과 군집 전처리는 양수인 관측값에 적용합니다. 0·음수·결측값은 별도 해석이 필요합니다.
- Spearman 상관관계는 인과관계를 나타내지 않습니다.
- 표준화된 군집 중심값은 원래의 물리적 영향계수가 아닙니다.
- 정제 CSV도 원자료를 기반으로 작성했으므로 원자료의 재이용·재배포 조건을 별도로 확인해야 합니다.

**중요:** 이 사이트의 산정은 등록한 개별 계수에 대한 *부분 계산*입니다. 시스템 경계, 기능단위, LCI 데이터, 배분, 대표성, 데이터 품질 검토가 빠진 상태에서 **ISO 14040/14044에 부합하는 완전한 LCA, PCF 또는 EPD 결과라고 주장할 수 없습니다.**

## 4. 실행 방법

### 정적 웹앱(GitHub Pages)

`main` 브랜치 루트를 Pages에 연결하면 `index.html`이 실행됩니다. 정적 앱은 서버나 계정 없이 브라우저에서 동작합니다.

```text
https://goalbangg-prog.github.io/Looply-mini-LCA/
```

로컬에서는 프로젝트 루트에서 아래 명령어로 정적 서버를 실행할 수 있습니다.

```bash
python -m http.server 8000
```

브라우저에서 `http://localhost:8000` 접속. 차트는 외부 Plotly CDN 연결이 필요합니다.

### Python Streamlit 프로토타입

```bash
pip install -r python/requirements.txt
streamlit run python/app.py
```

Python 프로토타입은 정적 웹앱과 별도로 보존했습니다. 분석 라이브러리와 알고리즘이 부분적으로 다르므로 결과 비교 시 주의가 필요합니다.
