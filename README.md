# LCA mini 계산기 🌱

한국환경산업기술원 **환경성적표지 평가계수(2021-08-02 파일)**를 활용한 환경영향계수 계산·탐색 학습 프로젝트입니다.

> **주의:** 이 도구는 LCA 개념 학습과 데이터 분석을 위한 미니 계산기입니다. ISO 14040/14044에 따른 완전한 제품 전과정평가, 제품탄소발자국(PCF), 환경성적표지(EPD) 인증 결과를 제공하지 않습니다.

## 프로젝트 목표
- 공개 평가계수 CSV를 Python으로 읽고 결측값·자료형·중복·단위를 점검합니다.
- 활동량 × 단위당 평가계수로 환경영향을 계산합니다.
- 환경영향계수를 탐색하고, 비슷한 계수 패턴을 군집화해 봅니다.
- Streamlit 프로토타입을 GitHub Pages용 정적 HTML/JavaScript 앱으로 전환합니다.

## 주요 기능
| 기능 | 내용 |
|---|---|
| 영향 계산 | 대분류·구분·원료 선택, 사용량 입력, 여러 항목 합산 |
| 영향 범주 | 탄소발자국, 자원발자국, 산성비, 부영양화, 물소모 |
| 단위 환산 | 질량·부피·에너지·수송량 내 호환 단위 환산 |
| 결과 확인 | 항목별 기여도 및 결과 CSV 저장 |
| 데이터 탐색 | 평가계수 분포·순위·상관관계 등 탐색 |
| 유사 항목 묶기 | Python 원형에서 로그 변환·표준화 후 KMeans 적용 |

정적 웹 버전은 Python 원형과 일부 시각화·군집화 구현이 다릅니다. **두 버전의 군집 결과가 일치한다고 보장하지 않습니다.**

## 계산 원리
각 영향 범주에 대해 다음 식을 적용합니다.

```text
환경영향량 = 사용량(평가계수의 기준 단위로 환산) × 해당 영향 범주의 평가계수
합계 = 계산 가능한 항목의 환경영향량 합산
```

예를 들어 kg당 탄소발자국 계수가 주어진 경우 사용량을 kg으로 환산한 뒤 곱합니다. **결측값('해당없음')은 0이 아닙니다.** 결측 계수가 있으면 해당 영향 범주의 합계가 불완전할 수 있습니다. 서로 다른 영향 범주(kg CO₂ eq, kg Sb eq 등)는 직접 더하지 않습니다.

## 데이터 전처리
Colab/Pandas에서 수행한 작업:
1. CSV 인코딩(UTF-8-SIG, CP949, EUC-KR 등) 확인
2. `해당없음` → `NaN`, 영향계수 열 숫자형 변환
3. 대분류·구분·단위별 빈도 및 결측률 점검
4. 원료명 중복과 복합키(대분류+구분+원료+단위) 중복 확인
5. 복수 영향계수가 동시에 존재하는 행 수 점검
6. UTF-8-SIG CSV로 정제 결과 저장

중복 항목을 무조건 삭제하지 않고, 구분과 단위를 함께 확인하도록 설계했습니다.

## 기술 스택
- **분석:** Python, Pandas, NumPy
- **프로토타입:** Streamlit, Altair, Scikit-learn(KMeans, StandardScaler, silhouette score)
- **정적 배포:** HTML, CSS, JavaScript, GitHub Pages

## 실행 방법
**정적 버전:** 저장소 루트의 `index.html`과 `lca_data.js`를 함께 유지합니다. GitHub 저장소의 Settings → Pages에서 main 브랜치의 /(root)를 배포 대상으로 지정합니다.

**Python 원형:** `python/app.py`와 정제 CSV를 같은 디렉터리에 두고 다음을 실행합니다.

```bash
pip install -r requirements.txt
streamlit run app.py
```
