# Looply 통계 분석 보고서 (2026-10-16)

## 분석 목적
공개 환경영향 평가계수 CSV의 결측, 영향범주 간 순위상관, 군집 패턴을 분석해 Python 데이터 분석 역량을 입증한다. 본 프로젝트는 제품 LCA 산정이 아니다.

## 데이터
출처: `data/lca_factors_clean.csv`. 전체 398행. 빈 셀은 결측으로 유지하고 0으로 대체하지 않는다. 대분류와 단위가 같은 항목끼리 비교한다.

## 발견 1: 영향범주별 데이터 완전성

| 영향범주 | 유효 | 결측 | 유효율 |
|---|---:|---:|---:|
| 탄소발자국 | 398 | 0 | 100.0% |
| 자원발자국 | 225 | 173 | 56.5% |
| 산성화 | 208 | 190 | 52.3% |
| 부영양화 | 191 | 207 | 48.0% |
| 물발자국 | 200 | 198 | 50.3% |

**발견:** 탄소발자국은 전 행에 계수가 있지만, 나머지 영향범주에는 상당한 결측이 있다.

**의미:** 서로 다른 영향범주를 동시에 분석할 때는 유효 표본 수가 줄어든다. 분석마다 유효 표본 수와 제외된 행 수를 함께 제시해야 한다.

**한계:** 결측의 원인은 CSV만으로 알 수 없으며, 결측을 영향 0으로 해석해서는 안 된다.

## 발견 2: 탄소발자국과 자원발자국의 순위상관

- 범위: 원료 및 에너지 생산 / kg
- 범위 전체: 186개
- 두 영향범주의 값이 모두 있는 항목: 179개
- Spearman 순위상관계수: **ρ = 0.744** (동순위 평균 처리)

**발견:** 해당 범위에서 탄소발자국 계수가 큰 항목은 자원발자국 계수의 순위도 높은 경향이 나타난다.

**의미:** 두 지표가 함께 높은 항목과 예외 항목을 산점도 및 원자료로 확인하는 탐색이 가능하다.

**한계:** 상관관계는 인과관계를 의미하지 않는다. 계수의 숫자 크기만으로 제품의 환경적 우열을 판단할 수 없다.

## 발견 3: 탐색적 군집 분석

동일 범위에서 탄소발자국과 자원발자국 계수가 모두 양수인 항목은 179개이다.

Python API는 `log10 → StandardScaler → scikit-learn KMeans(random_state=42,n_init=10)` 순서로 분석하며 군집별 크기, 상대적으로 두드러진 영향범주, 예시 항목, 실루엣 점수를 반환하도록 구현했다.

**검증 미완료:** 실제 Python 서버 실행으로 얻은 군집별 개수와 실루엣 수치는 이번 보고서에 포함하지 않았다. 실행 결과를 확인하지 않은 숫자는 제시하지 않는다. 군집 번호는 환경성 순위가 아니다.

## 시각화와 통계 일치성 점검

- **군집 분석 실행** 버튼은 이제 Python `/api/cluster-insight`를 호출한다. 서버에서 반환한 `assignments`와 `profiles`를 이용해 군집별 막대그래프, 항목별 표, 군집 카드 및 AI 해설을 **동일 응답**에서 그리도록 변경했다.
- **군집 수 추천** 버튼도 Python API의 실루엣 점수로 k=2~6을 비교한다. 분석 범위에 따라 유효한 k만 비교한다.
- **상관관계**: Python Spearman 계수와 유효 표본 수를 결과 영역에 표시하도록 구현했다. 기존 브라우저 산점도/상관 히트맵과 동일 범위 및 결측 처리인지 추가 브라우저 검증이 필요하다.
- **검증 상태**: 코드 수준에서 단일 API 결과를 공유하도록 변경했지만, 브라우저 E2E 테스트 통과 및 실제 Render 화면 확인은 아직 완료되지 않았다.

## 재현성 및 남은 검증

원자료: `data/lca_factors_clean.csv`; API: `/api/statistical-insight`, `/api/correlation-insight`, `/api/cluster-insight`; 테스트: `tests/test_api.py`.

테스트 코드 추가는 완료했지만 실행 통과와 Render 배포는 아직 검증하지 않았다. 포트폴리오 제출 전 API 테스트, 화면 표시, 브라우저/서버 분석의 정합성을 확인해야 한다.
