# Looply 데이터 분석 → 주요 발견 → AI 해석 설계

## 프로젝트 범위
Looply는 공개 환경영향 평가계수 CSV의 데이터 품질·분포·상관·군집을 탐색하는 Python 데이터 분석 포트폴리오입니다. 완전한 LCA, PCF, EPD 산정 엔진을 목표로 하지 않습니다.

## 처리 파이프라인
1. 원자료 및 기준 단위 확인. 결측은 0으로 대체하지 않습니다.
2. Python으로 재현 가능한 통계 계산(유효율, 중앙값, 사분위범위, IQR 이상치, 향후 상관계수 및 군집별 요약).
3. 통계량에 기반한 **발견**을 결정론적으로 생성하고 분석 표본 수를 함께 표시합니다.
4. 생성형 AI는 확정된 발견의 **쉬운 의미**와 **해석상 한계**만 설명합니다. 숫자나 원인 추정은 새로 만들지 않습니다.
5. AI 실패 시 검증된 기본 해설을 보여주고 생성 여부를 구분합니다.

## 화면 설계
- 분석 리포트: 차트 옆에 해당 분석의 핵심 발견, 해석, 주의사항.
- 데이터 인사이트: 선택된 대분류·단위·영향범주에 따라 표본 수, 결측률, 분포 통계, 이상치를 재계산.
- 군집 분석: 실제 실행 결과의 군집별 크기·중심값·실루엣 점수를 받아 설명(후속).
- 환경영향 계산: 기존 계산기 유지. 포트폴리오의 주력 분석 성과와 혼동하지 않도록 보조 기능으로 설명.

## 구현 상태 (2026-10-16)
- 구현: `POST /api/statistical-insight`의 CSV 재계산, 범위별 통계, UI 조회 버튼, 관련 테스트 코드.
- 기존 구현: 계산 결과 기반 AI 해설 `POST /api/calculation-insight`.
- 미구현: 통계 결과를 생성형 AI의 안전한 자연어 해석에 연결, 군집 결과의 Python 기반 재현 검증, 각 차트별 완전한 분석 결과 연동.
- 검증 필요: GitHub Actions, Render API·프론트 최신 커밋 배포, 브라우저 반응형 레이아웃.

## 취업용 증거
각 분석마다 질문 → 데이터 선택 이유 → 전처리 → Python 통계 코드 → 핵심 발견 → 해석상 한계 순으로 기록합니다. AI 문장은 보조적 전달 수단으로 취급합니다.
